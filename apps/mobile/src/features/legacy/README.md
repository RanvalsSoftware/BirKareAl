# Preserved legacy creative routes

These files preserve the pre-build-12 portrait, filter, trend, and generic creation screens without shipping them as customer-accessible Expo Router routes.

The App Store build is intentionally focused on the product/catalog workflow in response to Guideline 4.3(b). The active route files redirect to `/studio`; no backend endpoints, purchase identifiers, user projects, or environment settings were deleted. Reintroducing a legacy tool requires a deliberate product decision, privacy review, localization pass, and App Review positioning update.
